# E-commerce Product Page

This is a solution to the [E-commerce Product Page challenge](https://www.frontendmentor.io/challenges/ecommerce-product-page-UPsZ9MJp6) on Frontend Mentor. This project showcases an interactive product page with features like image galleries, cart functionality, and responsive design.

## Overview

### Features

- Interactive image gallery with thumbnail navigation.
- Add to cart functionality with quantity adjustments.
- Responsive design for mobile and desktop views.
- Ability to change product images in the cart.
- Clear cart functionality.
